# Getting started

Weave is a Spicetify custom app for editing playlists in Spotify Desktop: reorder tracks, inspect audio features, pull recommendations, Flowify order, and generate new lists.

## Open Weave

1. Install and enable the app (see [Install](../README.md#install)).
2. In Spotify’s sidebar, click **Weave**.

## Main layout

![Header and toolbar](screenshots/header-toolbar.png)

From top to bottom:

1. **Title** — Weave and the short tagline.
2. **Toolbar** — playlist picker on the left; actions (Undo … Save as new) on the right.
3. **Track table** — the playlist you are editing, with feature columns.

![Full app with a playlist open](screenshots/overview.png)

## First steps

1. Pick a playlist in the dropdown ([Playlist picker](playlist-picker.md)).
2. Wait for tracks and features (BPM, key, energy, …) to load.
3. Drag rows to reorder ([Arranging tracks](arranging-tracks.md)).
4. Use **Save** (owned playlists) or **Save as new** when you like the order ([Save and history](save-and-history.md)).

Click the keyboard icon in the header for [keyboard shortcuts](keyboard-shortcuts.md) (or press `?`).
