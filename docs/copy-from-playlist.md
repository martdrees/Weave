# Copy from Playlist

Import tracks from another playlist into the one you are editing.

![Toolbar — Copy from Playlist](screenshots/toolbar-actions.png)

Shortcut: **`Ctrl/⌘ Shift C`**

## Steps

1. Load the **destination** playlist in Weave.
2. Click **Copy from Playlist**.
3. Choose a source:
   - **Your library** — pick another playlist you own/follow from the list, or
   - Search playlists by name.
4. Wait for the source tracks to load.
5. Select tracks to import:
   - Click rows to toggle selection
   - **Select new** — select tracks not already in your playlist
   - **Clear** — clear selection
   - **Add all new** — import every track that is not already present
6. Click **Import selected**.

Rows labeled **In playlist** are already in your list and are skipped for “new” helpers.

## Notes

- Only **new** tracks are added; duplicates are ignored.
- Short messages report counts (e.g. *Added 12 tracks*) or *No new tracks to add*.
- Import updates the local editor — use [Save](save-and-history.md) to write Spotify.
