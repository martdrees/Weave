# Add Track

Search the Spotify catalog and append a track to the current playlist editor.

![Toolbar — Add Track](screenshots/toolbar-actions.png)

Shortcut: **`Ctrl/⌘ Shift A`**

## Steps

1. Load a playlist.
2. Click **Add Track** (or use the shortcut).
3. Type a query in *Search tracks…* and press **Search** (or Enter).
4. Browse results (title, artist, features when enrichment succeeds).
5. Click **Add** on a result.

Tracks already in the playlist are marked so you do not add duplicates. On success a short message appears (e.g. *Added “Track name”*), and the row shows in the table.

## Tips

- Prefer [Recommendations](recommendations.md) when you want many similar tracks with feature filters.
- Prefer Add Track when you know the song name or artist.
- Close the dialog with **Esc** or the close control.
