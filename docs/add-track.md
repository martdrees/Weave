# Add Track

Search the Spotify catalog and append tracks to the current playlist editor.

![Toolbar — Add Track](screenshots/toolbar-actions.png)

Shortcut: **`Ctrl/⌘ Shift A`**

## Songs or Artists

Use the **Songs | Artists** switch at the top of the dialog.

### Songs

1. Load a playlist.
2. Open **Add Track** (or use the shortcut).
3. Stay on **Songs**, type a query, and press **Search** (or Enter).
4. Browse results and click **Add**.

### Artists

1. Switch to **Artists**.
2. Type an artist name — suggestions appear as you type (from 2 characters).
3. Pick an artist to load their **top tracks**.
4. **Add** individual tracks, or **Add all new** to append every track not already in the playlist.
5. Use **← Artists** to go back to suggestions.

Tracks already in the playlist are marked so you do not add duplicates. On success a short message appears, and new rows flash in the table.

## Tips

- Prefer [Recommendations](recommendations.md) when you want many similar tracks with feature filters.
- Prefer Add Track when you know the song or artist name.
- Close the dialog with **Esc** or the close control.
